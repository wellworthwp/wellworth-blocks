# WellWorth Blocks

*Built to serve. Made to last.*

WellWorth Blocks is the free companion plugin to the WellWorth WordPress block theme. Ships the basic Donation, Event, Sermon, and Language Switcher blocks used by the free Foundation tier. Pro versions of these blocks live in `wellworth-pro` (paid). GPL-2.0-or-later, submitted to the WordPress.org plugin directory.

- **Licence:** GPL-2.0-or-later (see `LICENSE`).
- **Distribution:** WordPress.org plugin directory.
- **Organisation:** [github.com/wellworthwp](https://github.com/wellworthwp).
- **Status:** Scaffolded; block implementations land progressively from task **T038** onward.
